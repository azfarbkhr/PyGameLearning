# Archived experiments

These are the original learning scripts and their original assets, moved here to keep the new game organized. Their asset paths are relative to the current working directory, so run a script with `__old` as the working directory.

For example, from the project root:

```powershell
Set-Location __old
..\.venv\Scripts\python.exe a7_got_attack_on_castle.py
```

Some archived experiments may need extra packages such as Pymunk. The current game's dependencies are defined by the root `pyproject.toml`.
