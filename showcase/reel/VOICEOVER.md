# Voiceover script

**Recording:** warm, conversational voice; the supplied take is about 49.5 seconds. The pronunciation guide was read after the narration, so it has been removed from the script and trimmed from the audio. The clean recording is `showcase/reel/assets/voiceover-clean.wav`.

While exploring the Codex SDK, I wanted to test its limits. So I tried making a game with Codex and ChatGPT, and using ChatGPT as the brain behind it.

I started with AI generated designs and a story.

Before a battle, the player can discuss a plan with the allies. Codex replies, and the discussion shapes orders that guide the team during the fight. I’m still tweaking how it works.

During battle, the player can press T and speak a command naturally. Codex currently translates a few short commands into movement orders. The team follows those orders, and I’m still working on the limits.

The enemy army also receives orders from Codex in the background. The player can press E to talk with Ramsay.

This is a learning project. The GitHub link is in the comments. I’d love to hear your ideas for making it better.
